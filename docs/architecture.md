## 8. 复用原则（**先比对，再决定**）

> **"复用"不是"搬代码"**——先看**能不能复用**，再比**谁更好**；**不能无视 Excel ≠ Word**（表格 ≠ 文本）。

| 步 | 做什么 |
|---|---|
| **1. 比对** | 把 Excel 的**能力/实现**与 Word 的**需求**逐项比：**谁更好、是否适用** |
| **2. 判定** | **能复用** / **部分复用** / **不能复用** |
| **3. 落地** | **能复用**：抽公共层或 **adapter**；**不能**：Word 独立实现 |
| **4. 红线** | **Excel 代码不能碰**（只读、只调，不改） |

**三条红线**：
1. **不无视 Excel ≠ Word**（表格 ≠ 文本）。
2. **Excel 代码不能碰**（只通过**接口/adapter** 用）。
3. **不能为了复用而扭曲**（Reuse 不能改变原语义）。

## 9. 小脑层（记忆）——**通用基础设施**

> **小脑 = 记忆**，是**独立于功能区**的**通用层**：Excel / Word / PDF **都用**；**不直接干活**，但**每个动作都靠它**。

| 层 | 属性 | 说明 |
|---|---|---|
| **小脑（通用）** | **共享** | 记忆（存储/检索/术语/热度/淘汰） |
| **记忆实例** | **分 namespace** | `excel` / `word` / `common` |
| **功能区** | **独立** | 只**调用**小脑，**不实现**记忆 |

### Excel 记忆 → Word 的"Word 化"（**适配，不改源码**）

| 做法 | 说明 |
|---|---|
| **Adapter** | 在 **Word 侧**写薄适配层，**调用** `memory_rag` 的**公共接口** |
| **不碰 Excel** | **不改** `block_cross_table/memory_rag/` 任何文件 |
| **namespace=`word`** | 术语/记忆**隔离** |
| **"Word 化"** | 把 Excel 的"列/术语"语义 → **Word 的"段落/术语↔锚点"** |

## 10. Word 操作清单（**规格 6 种，现做 1 种**）

> 规格：`op_type = ["replace","insert","delete","move","format","tracked_change"]`

| op_type | 状态 | 优先级 |
|---|---|---|
| **`replace`** | ✅ 已做 | — |
| **`insert`** | ❌ 未做 | **P0** |
| **`delete`** | ❌ 未做 | **P0** |
| **`format`** | ❌ 未做 | **P1** |
| **`move`** | ❌ 未做 | **P2** |
| **`tracked_change`** | ❌ 未做 | **P3** |

**读能力**：段落/样式/大纲 ✅；修订 ❌；批注 ❌；交叉引用 ⚠️ 部分。
