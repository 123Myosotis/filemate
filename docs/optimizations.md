## 二、⏳ 待排期（**值得，但未做**）

| # | 项 | 为什么值得 | 代价 |
|---|---|---|---|
| 1 | **`move` 带完整句 / 跨段** | 更自然 | **越界风险** |
| 2 | **`outline` 自动重排编号** | 编号整齐 | **跨段状态**易错 |
| 3 | **模板类成稿**（用户定） | **不限于**合同/报告：骨架+槽位 → 另存 | ✅ **P2B 最小版**：`{{/【/｛` 槽 + 指令/材料 KV；缺槽不填；`pipeline/content_split/template_fill.py` |
| 4 | **长文风格仿写**（用户定） | 小说等长文，学语气/叙事再写 | **仍暂不做**；与 #3 分产品、分入口 |

> **原则**：① 模板类 ≠ 自由写长文；② 仿写单独入口，本刀不做；③ 结构拆段（P2A）与模板填槽（P2B）同属成稿族、分触发。

## 三、❌ 不划算（**明确不做**）

| # | 项 | 为什么不做 |
|---|---|---|
| 1 | **自动分块** | **语义不清**——单 op 分块**不改变结果**，强分只增复杂度 |
| 2 | **pytest-qt 真点击** | **flaky**（沙箱 GUI 不稳），维护成本高 |
| 3 | **`outline` 自动重排**（当前） | 同上（#4 待排期，但**优先级低**） |
| 4 | **沙箱 55/106** | **不是代码**——ACL 报告 **`NOT_THIS_CLASS`**，**是 DSH 沙箱**；**要 full access** |

### P1 去重与置信（已改判，待做）

**代码事实**：重复来自每次 `_unique_dest` 无内容 hash；清单已有；只扫顶层；短文门槛 8；密度 `×1000/n` + 全零兜底 `technical`。

| 优先 | 做 | 不做（已否决） |
|---|---|---|
| 1 | `内容分类/` 下 sha256→路径索引，命中则跳过（内容相同） | 默认覆盖同名 |
| 2 | 清单补列：状态 / 得分 top2 / 跳过原因（扩展现有 md） | 默认 `日期/` 快照树 |
| 3 | 可选「含一层子目录」；跳过 0 字节、解析失败、超大 | 跑前自动清理产物 |
| 4 | 仅低分（最高≤0 或 top1−top2 过小）调模型，固定枚举选 1 类 + hash 缓存；非法→「其他」 | 无 Key 假装语义聚类 |
| — | 门槛 50~100 字；低置信不硬判；`DEFAULT`→「其他/未确定」或清单标低置信；`DOC_TYPES`+`TYPE_LABELS` 收成单一来源 | |
